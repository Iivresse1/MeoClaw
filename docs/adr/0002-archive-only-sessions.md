# 会话只能归档

**Status**: accepted

正式产品不再提供永久删除会话的 UI 或 API。归档会话保留数据库记录、消息、
workspace 和 checkpoint；用户查看归档会话历史，但必须恢复后才能继续发送任务。
归档项与活动会话按原会话创建时间统一排序，以淡色显示；默认隐藏，由“新任务”
旁的圆形按钮显示或隐藏。

升级到该模型时，旧 `chat / workspace / system` 会话数据库和对应工作区直接
清空，不生成迁移备份。该一次性迁移由用户明确确认，不属于产品内的删除能力。

## Consequences

- `DELETE /api/sessions/{id}` 将被归档和恢复接口取代。
- 当前被归档的会话仍可查看，但输入框必须锁定，直到执行恢复。
- 历史数据会持续占用会话 workspace 和 checkpoint 空间。
